# Retainer review

Each retainer period is its own project. Overage is used minutes above the allowance, not an automatic extra charge. Do not roll unused hours into another period without an agreed rule.

```bash
node scripts/agency.mjs retainer-review
```

Substitute the operator's values for placeholders. Add --json for structured output. If a match is ambiguous, show the candidates and get an exact choice. Never invent records or send anything. See docs/cli.md for optional flags and rules.
