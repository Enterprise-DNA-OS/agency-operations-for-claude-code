# Why there is no front end

An operations manager needs answers and reliable record changes: budget versus remaining work, written scope approvals, retainer usage and capacity after leave. These commands operate on one database. Claude Code, Codex, OpenCode or Cursor provides the conversational door.

The HTML files are read-only snapshots. They cannot log time, approve work or stay current without regeneration. A screen adds mobile entry, timers, drag-and-drop scheduling, permissioned staff self-service and live collaboration. Those are not included in this free base. It has no offline synchronisation or calendar connection.

Omni by Enterprise DNA can build the team's web workspace and connections around these records. A configured production system also needs authenticated users, backups and operational support. The database and its business rules remain yours.
